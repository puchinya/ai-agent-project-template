# Design

Durable internal architecture lives here. This README is the ownership index: it tells readers which design owns an architecture area and links to that single owner. It does not restate design decisions.

Start new documents from the [design template](../templates/design-template.md) and follow the [design standard](../standards/design.md).

## Ownership map

There are no durable designs in this starter scaffold yet. Add one row for each approved architecture area when its owner document exists.

| Architecture area | Owner |
|---|---|
| Project profile validation, context routing, runtime host, and hook composition | [Project Profile and Context Design](project-profile-context-design.md) |

For large projects, add nested README indexes under category directories and link those categories here. Every navigation link must be meaningful and clickable.

Do not duplicate public contracts; link to their [specification owners](../specs/README.md). File naming: use `-design.md` for durable documents.
