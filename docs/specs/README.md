# Specifications

Normative public and observable contracts live here. This README is the ownership index: it tells readers where each semantic rule belongs and links to its single owner. It does not restate contract rules.

Start new documents from the [specification template](../templates/spec-template.md) and follow the [specification standard](../standards/specification.md).

## Ownership map

There are no durable specifications in this starter scaffold yet. Add one row for each approved semantic area when its owner document exists.

| Semantic area | Owner |
|---|---|

The fenced example shows link syntax only; replace it with a link to an existing owner before using it:

```markdown
| Export contract | [Export specification](export-spec.md) |
```

For large projects, add nested README indexes under category directories and link those categories here. Every navigation link must be meaningful and clickable.

Do not document implementation architecture here. File naming: use `-spec.md` for durable documents.
