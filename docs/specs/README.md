# Specifications

Normative public and observable contracts live here. This README is the ownership index: it tells readers where each semantic rule belongs and links to its single owner. It does not restate contract rules.

Start new documents from the [specification template](../templates/spec-template.md) and follow the [specification standard](../standards/specification.md).
